# gl-docs

Preview of the Global Ledger API documentation and User Guide.

- Start page: https://ivan-osypchuk.github.io/gl-docs/
- API Documentation v4.1: https://ivan-osypchuk.github.io/gl-docs/api-docs/
- User Guide v1.3: https://ivan-osypchuk.github.io/gl-docs/user-guide/

The repository holds the finished websites as zip archives. The workflow in
`.github/workflows/pages.yml` unpacks them and publishes them with GitHub Pages
on every change. To update a site, upload a new archive with the same name.
